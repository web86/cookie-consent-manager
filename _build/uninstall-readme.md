## Uninstall / Удаление

Штатное удаление через Package Manager очищает подтверждённые объекты и файлы компонента. Журналы согласий, пользовательские пути, изменённые адаптеры и неизвестные файлы сохраняются. Предупреждения перечисляют оставленные данные. Для полной очистки владелец сайта может отдельно сохранить или удалить именно эти файлы; произвольные каталоги журналов автоматически не очищаются. Сохранённые пользовательские файлы могут блокировать новую чистую установку до ручного решения владельца.

Native Package Manager uninstall removes confirmed package objects/files. Consent logs, custom paths, modified adapters and unknown files remain. Review the uninstall warnings before separately archiving or deleting retained data. Retained files can intentionally block a fresh install. If uninstall reports an error, correct the reported condition and retry; no successful full removal is claimed until completion.
