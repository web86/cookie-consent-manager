# Быстрый старт

## Установка

1. Сделайте резервную копию БД, `core/`, `assets/`, шаблонов и существующих журналов.
2. Установите транспортный пакет **для вашей версии MODX** штатным менеджером пакетов. MODX 2 и MODX 3 используют разные ветки и семейства пакетов.
3. Откройте **Пакеты → Cookie Consent Manager** (положение в меню зависит от интерфейса MODX).
4. В **Сервисах** включите необходимую категорию для показа посетителю, затем нужные сервисы и задайте действительные идентификаторы.
5. На вкладке **Тексты** проверьте надписи и язык; 
6. Сохраните изменения. Для аудита укажите каталог журналов, доступный PHP на запись и недоступный посетителям по HTTP.

Новая установка не должна неожиданно запускать необязательные сервисы: сначала настройте их явно.

## Рекомендуемый способ подключения

Добавьте в общий шаблон MODX один вызов например в `<head>`:

```html
<head>
    [[!CookieConsentAssets]]
</head>
```

И один вызов например перед `</body>`:

```html
<body>
    <!-- Контент сайта -->
    [[!CookieConsentBanner]]
</body>
```

Добавьте в futer сайта кнопку для вызова окна настроек <button type="button" data-cookie-settings-open>Настройки cookie</button>

Теги вызова **некешируемые** (`[[!…]]`). Для Fenom используйте форму вызова, которую ваш шаблон гарантированно не преобразует, например `{'!CookieConsentAssets'|snippet}` и `{'!CookieConsentBanner'|snippet}` при корректной настройке pdoTools/Fenom.

Для старой интеграции допустим **один** `[[!CookieConsent]]` вместо пары Assets/Banner. **Не смешивайте** оба способа и не вставляйте один и тот же вызов несколько раз.

## Перенос существующих скриптов

Если счётчик уже подключён отдельным `<script>` или через иной менеджер тегов, удалите их и используйте настройки сервисов в пакете Cookie Consent Manager.

## Проверка после настройки

Откройте страницу в приватном окне с вкладкой браузера **Network**:

1. В Strict до выбора не должно быть запросов к необязательным SDK/iframe, которые контролирует компонент.
2. Разрешите аналитику и убедитесь, что нужный счётчик загружается.
3. Отклоните необязательные категории, затем обновите страницу: они не должны запускаться.
4. Откройте настройки повторно через `data-cookie-settings-open`.
5. Проверьте событие в [журнале согласий](audit) и соответствующую запись на сервере.

::: tip
Проверяйте не только внешний вид баннера, но и **реальные сетевые запросы** до и после выбора.
:::
