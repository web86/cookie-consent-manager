# Cookie Consent Manager 1.0.0 — Release Notes

Первый стабильный релиз native MODX 2 пакета. MODX Revolution 2.8.8, PHP 8.1+. Канонический источник — `main`, аннотированный тег `v1.0.0` после завершения приёмки. Deployment клиентских сайтов не выполняется.

- Независимая видимость необязательных категорий и доступные сворачиваемые разделы Manager. Однократная миграция beta32 сохраняет прежнюю видимость; версии категорий предотвращают восстановление отозванных разрешений при скрытии/включении.
- `onAllowed()` с опциональной привязкой к экземпляру/fingerprint, `stillAllowed()` и `unsubscribe()`; примеры пользовательских JS-карт.
- Удаление ClientID → форма/Битрикс24 из ядра. Legacy boolean нормализуется; изменённая Метрика требует повторного согласия. Необязательный пользовательский чанк документирован.
- Корректное сохранение переводов свежей установки: пустые словари, которые MODX выдаёт как [], нормализуются до редактирования и после Save. Непустые некорректные массивы отвергаются.
- PHP-локализация и пользовательские overrides; Assets один раз в head, Banner один раз в body, один min JS и CSS, content-hash cache busting; legacy integration сохранена.
- GA4/GTM/Ads/Метрика/Mail.Ru/VK/Meta, дополнительные экземпляры; строгие category/fingerprint guards, placeholders карт, отзыв и reload. GTM использует маркетинг с отдельными Consent Mode v2 состояниями; consent checks внутри контейнера настраивает администратор.
- Общий Save и локальная проверка каталога без self-request; Audit Viewer/CSV, права доступа, JSONL schema 1/2, сохранность ключей/прошлых журналов.
- Штатный Package Manager, предупреждение о замене canonical source на месте, сохранение IDs/category/properties, без stock-копий и plugins. Настройки/переводы/HTML/журналы сохраняются. Uninstall оставляет пользовательские DB-данные; универсального атомарного файлового rollback нет.

Установка: backup → проверить SHA256 → MODX Package Management Upload/Install/Upgrade → настроить категории/сервисы и журнал → очистить MODX/HTML cache → staging. [Полная инструкция](../README.md), [точная приёмка](modx2-1.0.0-acceptance.md).

Пакет: `cookieconsent-1.0.0.transport.zip`. SHA256: `0ed4563a2e92cf5e40ba1c269dc0d39bd0acdb6b3fb12a86f734983ce2f4b04b`. Две независимые сборки modPackageBuilder после нормализации совпали побайтно; 70 native vehicles (14 object, 54 file, 2 script), 134 ZIP entries.

Реальная доставка Meta/VK/GA/Ads/Битрикс24 и deployment на клиентах не проверены. Контролируемые SDK doubles подтверждают consent/network/очереди, а не работу кабинетов. Реальный владелец GTM тестировал опубликованный безопасный контейнер; настройки произвольных сторонних тегов требуют отдельной приёмки владельцем. Полный список NOT RUN приведён в отчёте.
